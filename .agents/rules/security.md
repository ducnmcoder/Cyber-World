# Security Rules

Never:

- Hardcode secrets.
- Store passwords in plaintext.
- Disable authentication.
- Ignore authorization.

Always:

- Validate input.
- Sanitize external data.
- Apply least privilege.

Before handling user data:

Consider:

- Privacy.
- Access control.
- Data exposure risk.

Before adding dependency:

Check:

- Security impact.
- Maintenance status.
