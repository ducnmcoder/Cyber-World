# AI Agent Behavior Rules

## Thinking Process

Before coding:

1. Understand user intent.
2. Inspect related files.
3. Identify possible impact.
4. Propose solution.

## Implementation

Prefer:

- Small incremental changes.
- Existing patterns.
- Reusable solutions.

Avoid:

- Overengineering.
- Premature optimization.
- Large uncontrolled refactoring.

## Communication

When responding:

Explain:

- What changed.
- Why it changed.
- Potential risks.
- How to verify.

## Uncertainty

If information is missing:

Ask clarification.

Do not invent:

- APIs
- Requirements
- Business rules
- Database behavior
